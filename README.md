# LarkPM

Windows 桌面需求工作台，连接可配置的飞书多维表格，提供需求流程看板、个人四象限和版本甘特。

## 功能

- 多项目连接、字段映射和状态映射；本地需求归类可独立于飞书父记录保存。
- 横向看板与自适应信息流。信息流按窗口宽度显示完整列，编辑任务保留需求所在列。
- 串行、并行和独立分支编排；上下游阻断检查。版本筛选后的编排只处理当前版本。
- 任务优先级沿用需求表选项；同一并行阶段、相同状态的任务按优先级排列。
- 个人四象限可独立使用，无需项目连接或 LinkinNotes。可选与 LinkinNotes 双向同步，独立待办不会进入飞书需求表。
- 周、双周、月甘特，按需求分组和折叠；可关联本项目测试排期和双端线上版本。
- 读取时优先显示需求，关联表在后台更新；失败保留上次缓存。
- 本地修改在“同步与回写”中手动提交；支持冲突比较、选择本地新增项发布和忽略。
- 托盘运行、自定义全局显示／隐藏快捷键、任务栏图标开关，以及窗口位置和大小记忆。

## 安装与使用

当前版本：**1.0.8**。运行 `LarkPM_1.0.8_x64-setup.exe`，或完整解压便携包并运行 `LarkPM.exe`。便携包需保留同目录的 `sidecar/larkpm-backend.exe`。系统需要 Microsoft Edge WebView2 Runtime。

1. 打开“设置 → 项目与连接”，填写需求表链接或 Base Token、Table ID。
2. 按表结构配置标题、起止时间、处理人、工作状态等字段；优先级默认对应“优先级”字段。
3. 配置飞书自建应用并授权，应用需具备对应表的读取／写入权限。密钥和授权凭证仅保存在本机。
4. 点击“读取飞书”。需求先更新，测试表和版本记录表在后台读取。
5. 编辑任务后，去“同步与回写”选择需要提交的修改；不会自动回写全部内容。

个人工作台无需飞书授权即可新增、编辑、分配象限和完成独立待办。开启可选同步后，LinkinNotes 暂不可用时仍保留本地操作；重新连接后再同步。

### 常用操作

- 在“设置 → 个性化”选择信息流或横向看板，以及甘特周期。
- 按住编排键拖动任务；阶段之间为串行，拖入阶段为并行，分支拖放区只连接指定节点。
- 节点编排键和状态键可在设置中调整，Ctrl＋点击多选，Esc 取消当前拖动。
- 全局窗口快捷键使用同一组合键显示／隐藏窗口；隐藏后仍在托盘运行。
- 空日期点击编辑时填入今天；Backspace 或 Delete 清空，保存后生效。
- 需求总览的任务同时满足“已完成＋验收通过”才隐藏；需求支持手动归档。

## 数据与同步

项目数据和个人待办保存在 `%LOCALAPPDATA%\LarkPM\workspace.db`；飞书凭证位于该目录的 `auth` 文件夹，窗口偏好位于应用配置目录。更新前建议备份本地数据。

需求读取和手动回写均保留冲突检查；关联测试表与版本记录表只读。版本值和优先级选项采用源表原文，不擅自合并命名相似的版本。人员状态与默认部门由本机维护，无需通讯录授权。

## 本地开发

需要 Node.js、Python 3.12、Rust 和 Windows C++ 构建工具。

```powershell
npm install
python -m pip install pyinstaller psutil
npm run tauri:dev
```

前端使用 React／TypeScript／Vite，桌面容器使用 Tauri 2，Python sidecar 负责 SQLite 和飞书接口。

```powershell
python -m unittest discover -s tests -v
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

打包结果位于 `release/`。测试使用临时工作区和模拟接口，不需要真实飞书写入权限。调试脚本和本地工作记录不包含在发行包中。
